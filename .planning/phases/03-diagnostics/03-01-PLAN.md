```c
/* Netlink attributes for TQUIC inet_diag */
enum {
    TQUIC_DIAG_ATTR_UNSPEC,
    TQUIC_DIAG_ATTR_INFO,        /* struct tquic_info */
    TQUIC_DIAG_ATTR_SCID,        /* Source CID (variable length) */
    TQUIC_DIAG_ATTR_DCID,        /* Dest CID (variable length) */
    TQUIC_DIAG_ATTR_VERSION,     /* QUIC version u32 */
    TQUIC_DIAG_ATTR_PATHS,       /* Nested: per-path info */
    TQUIC_DIAG_ATTR_STREAMS,     /* Stream count u32 */
    __TQUIC_DIAG_ATTR_MAX,
};

/* Per-path nested attributes */
enum {
    TQUIC_DIAG_PATH_UNSPEC,
    TQUIC_DIAG_PATH_ID,          /* u32 path_id */
    TQUIC_DIAG_PATH_STATE,       /* u8 enum tquic_path_state */
    TQUIC_DIAG_PATH_RTT,         /* u32 smoothed RTT (us) */
    TQUIC_DIAG_PATH_CWND,        /* u32 cwnd (bytes) */
    TQUIC_DIAG_PATH_TX_BYTES,    /* u64 bytes transmitted */
    TQUIC_DIAG_PATH_RX_BYTES,    /* u64 bytes received */
    TQUIC_DIAG_PATH_LOST,        /* u64 lost packets */
    __TQUIC_DIAG_PATH_MAX,
};

/* Basic info structure for ss output */
struct tquic_info {
    __u8  state;           /* enum tquic_conn_state */
    __u8  num_paths;       /* active path count */
    __u16 num_streams;     /* open stream count */
    __u32 rtt_us;          /* connection RTT (us) */
    __u64 tx_bytes;        /* total bytes sent */
    __u64 rx_bytes;        /* total bytes received */
    __u64 retransmits;     /* retransmission count */
};
```

<task type="auto">
  <name>Task 2: Implement tquic_diag.c inet_diag handler</name>
  <files>net/tquic/tquic_diag.c, net/tquic/Makefile, include/net/tquic.h</files>
  <action>
Create net/tquic/tquic_diag.c following MPTCP pattern (net/mptcp/mptcp_diag.c).

Implement:
1. **tquic_diag_handler** structure with:
   - .owner = THIS_MODULE
   - .dump = tquic_diag_dump (iterate all TQUIC connections)
   - .dump_one = tquic_diag_dump_one (single connection by cookie)
   - .idiag_get_info = tquic_diag_get_info (fill struct tquic_info)
   - .idiag_get_aux = tquic_diag_get_aux (extended info: CIDs, paths)
   - .idiag_type = IPPROTO_TQUIC (263)
   - .idiag_info_size = sizeof(struct tquic_info)

2. **tquic_diag_dump()**: Iterate tquic_sock hash table (or connection list). For each socket in the requested network namespace, call inet_sk_diag_fill(). Use RCU protection for iteration.

3. **tquic_diag_dump_one()**: Look up single connection by cookie. Return -ENOENT if not found.

4. **tquic_diag_get_info()**: Fill struct tquic_info with:
   - state from conn->state
   - num_paths from conn->num_paths
   - num_streams (count from conn->streams rb-tree)
   - rtt_us from active_path->stats.rtt_smoothed
   - tx_bytes/rx_bytes from conn->stats
   - retransmits from conn->stats.retransmissions

5. **tquic_diag_get_aux()**: For CAP_NET_ADMIN callers, add extended attributes:
   - SCID/DCID in raw bytes (full hex display in userspace)
   - QUIC version
   - Per-path breakdown using nested NLA attributes

Per RESEARCH.md pitfall #4: Add MODULE_ALIAS_NET_PF_PROTO_TYPE for auto-loading:
   MODULE_ALIAS_NET_PF_PROTO_TYPE(PF_NETLINK, NETLINK_SOCK_DIAG, 2-263)

Per RESEARCH.md pitfall #5: Filter by net_eq(sock_net(sk), seq_file_net(seq)) for namespace isolation.

6. **State name mapping**: Create static array tquic_state_names[] per 03-RESEARCH.md:
   ```c
   static const char *tquic_state_names[] = {
       [TQUIC_CONN_IDLE]       = "IDLE (CLOSED)",
       [TQUIC_CONN_CONNECTING] = "CONNECTING (SYN_SENT)",
       [TQUIC_CONN_CONNECTED]  = "CONNECTED (ESTABLISHED)",
       [TQUIC_CONN_CLOSING]    = "CLOSING (FIN_WAIT1)",
       [TQUIC_CONN_DRAINING]   = "DRAINING (TIME_WAIT)",
       [TQUIC_CONN_CLOSED]     = "CLOSED (CLOSED)",
   };
   ```

7. Add tquic_diag_init() and tquic_diag_exit() for module init/exit. Call inet_diag_register/unregister.

8. Update net/tquic/Makefile to include tquic_diag.o in tquic-y.

9. Add declaration in include/net/tquic.h:
   ```c
   int __init tquic_diag_init(void);
   void __exit tquic_diag_exit(void);
   ```

Note: For now, connection iteration can use a simple approach. If there's no global connection hash, iterate the tquic_sock via inet socket iteration or implement a minimal hash. Phase 4 will add proper global CID hash.
