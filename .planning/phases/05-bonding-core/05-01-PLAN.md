```c
static const char *tquic_bonding_state_names[] = {
    [TQUIC_BOND_SINGLE_PATH] = "SINGLE_PATH",
    [TQUIC_BOND_PENDING]     = "PENDING",
    [TQUIC_BOND_ACTIVE]      = "ACTIVE",
    [TQUIC_BOND_DEGRADED]    = "DEGRADED",
};
```

3. tquic_bonding_init():
   - Allocate and zero bonding context
   - Initialize spinlock, set state to SINGLE_PATH
   - Set max_buffer_bytes to TQUIC_DEFAULT_BUFFER_SIZE
   - Store pm back-pointer
   - Register callbacks with path manager (pm->on_path_available = tquic_bonding_on_path_validated, etc.)
   - Return context

4. tquic_bonding_destroy():
   - If reorder buffer allocated, free it (stub for 05-02: tquic_reorder_destroy())
   - Accumulate time_in_bonded if currently bonded
   - kfree context

5. tquic_bonding_update_state() - THE CORE STATE MACHINE:
   - Lock state_lock
   - Count paths: call tquic_pm_get_active_paths() or iterate pm->path_list
   - validated = paths in VALIDATED or ACTIVE state
   - failed = paths in FAILED state
   - Determine new_state:
     * validated == 0: SINGLE_PATH (connection closing)
     * validated == 1 && failed == 0: SINGLE_PATH
     * validated == 1 && failed > 0: DEGRADED (was bonded, lost paths)
     * validated >= 2 && failed == 0: ACTIVE
     * validated >= 2 && failed > 0: DEGRADED
   - If state changed:
     * Log transition: pr_info("bonding: %s -> %s (validated=%d failed=%d)\n", ...)
     * Update stats.state_changes
     * Handle buffer lifecycle:
       - Entering BOND_PENDING or ACTIVE from SINGLE_PATH: lazy-allocate reorder buffer
       - Entering SINGLE_PATH from ACTIVE/DEGRADED: free reorder buffer (if empty)
     * Track bonded time: if leaving ACTIVE, accumulate time
   - Unlock
   - If state changed to ACTIVE or DEGRADED, recalculate weights

6. tquic_bonding_derive_weights() - capacity-proportional weighting:
   - Lock pm->lock
   - For each path in pm->path_list:
     * Skip if not VALIDATED or ACTIVE
     * If user_override[path_id], keep user weight
     * Else calculate: capacity = cwnd * USEC_PER_SEC / srtt (bytes per second)
     * Scale to weight 1-1000 range
     * Apply minimum floor (TQUIC_MIN_PATH_WEIGHT = 50 = 5%)
   - Calculate total_weight
   - Unlock
   - Update weights.last_update = ktime_get()
   - Increment stats.weight_updates

7. tquic_bonding_set_path_weight() - sockopt handler:
   - Validate weight in range [TQUIC_MIN_PATH_WEIGHT, TQUIC_MAX_PATH_WEIGHT]
   - Set weights.path_weights[path_id] = weight
   - Set weights.user_override[path_id] = true
   - Recalculate total_weight
   - Return 0

8. Callback implementations:
   - tquic_bonding_on_path_validated(): call tquic_bonding_update_state()
   - tquic_bonding_on_path_failed(): call tquic_bonding_update_state()

9. Export symbols:
   - EXPORT_SYMBOL_GPL(tquic_bonding_init)
   - EXPORT_SYMBOL_GPL(tquic_bonding_destroy)
   - EXPORT_SYMBOL_GPL(tquic_bonding_update_state)
   - EXPORT_SYMBOL_GPL(tquic_bonding_derive_weights)
   - EXPORT_SYMBOL_GPL(tquic_bonding_set_path_weight)

10. Update net/quic/Makefile to add tquic_bonding.o to obj-$(CONFIG_QUIC).

Note: The reorder buffer functions (tquic_reorder_*) are stubs for now - Plan 05-02 implements them. Use conditional compilation or stub functions that return success/do nothing.
