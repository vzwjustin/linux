<objective>
Add lockdep annotations for TQUIC socket locks to enable runtime lock validation.

Purpose: Lockdep is the kernel's runtime lock validator. Without proper annotations, lockdep cannot distinguish between different TQUIC socket instances and will report false positives when handling parent/child socket relationships or nested locking. This is critical for multi-path scenarios where connections have multiple paths with their own locks.

Output: Lock class key definitions, sock_lock_init_class_and_name calls in socket init, inline lock documentation.
</objective>

/*
 * Initialize lockdep class for this socket
 * This allows lockdep to distinguish between IPv4 and IPv6 sockets
 * and properly validate lock ordering
 */
static void tquic_set_lockdep_class(struct sock *sk, bool is_ipv6)
{
	sock_lock_init_class_and_name(sk,
		is_ipv6 ? "slock-AF_INET6-TQUIC" : "slock-AF_INET-TQUIC",
		&tquic_slock_keys[is_ipv6],
		is_ipv6 ? "sk_lock-AF_INET6-TQUIC" : "sk_lock-AF_INET-TQUIC",
		&tquic_lock_keys[is_ipv6]);
}
