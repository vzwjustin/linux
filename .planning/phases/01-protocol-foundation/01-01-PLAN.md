Insert after IPPROTO_MPTCP=262 and before IPPROTO_MAX:

```c
  IPPROTO_MPTCP = 262,		/* Multipath TCP connection		*/
#define IPPROTO_MPTCP		IPPROTO_MPTCP
  IPPROTO_TQUIC = 263,		/* Transport QUIC with multipath	*/
#define IPPROTO_TQUIC		IPPROTO_TQUIC
  IPPROTO_MAX
};
```

Follow the exact format of existing entries:
- Two-space indent for enum value
- Tab-aligned comment
- #define alias on next line with #define flush left

Why 263: Next available after MPTCP=262. SMC=256 is already used. Values > 255 are valid for IPPROTO in Linux.
