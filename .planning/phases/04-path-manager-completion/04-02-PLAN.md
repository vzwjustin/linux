<task type="auto">
  <name>Task 2: Create PM-specific genetlink family with multicast</name>
  <files>
    net/tquic/pm/pm_netlink.c
    net/tquic/pm/Makefile
  </files>
  <action>
Create a dedicated PM netlink family (separate from tquic_netlink.c bonding interface):

1. Create `net/tquic/pm/pm_netlink.c` with:

   **Multicast groups** (following MPTCP pattern):
   ```c
   #define TQUIC_PM_CMD_GRP_OFFSET  0
   #define TQUIC_PM_EV_GRP_OFFSET   1

   static const struct genl_multicast_group tquic_pm_mcgrps[] = {
       [TQUIC_PM_CMD_GRP_OFFSET] = { .name = TQUIC_PM_CMD_GRP_NAME },
       [TQUIC_PM_EV_GRP_OFFSET]  = { .name = TQUIC_PM_EV_GRP_NAME,
                                     .flags = GENL_MCAST_CAP_NET_ADMIN },
   };
   ```

   **Attribute policies**:
   - Main policy for commands
   - Nested policy for address attributes (mptcp_pm_address_nl_policy pattern)

   **Address parsing helper** (`tquic_pm_parse_addr`):
   - Parse nested address attributes
   - Set extended ACK error messages for each failure (pitfall #6)
   - Support both IPv4 and IPv6

   **Address filling helper** (`tquic_pm_fill_addr`):
   - Build nested address attribute from tquic_addr_info
   - Used in replies and events

   **Command handlers**:
   - `tquic_pm_nl_add_path`: Parse address, find connection by token, call pm_ops->add_path or direct tquic_conn_add_path, set extack on error
   - `tquic_pm_nl_del_path`: Find connection and path, call tquic_conn_remove_path
   - `tquic_pm_nl_get_path`: Return path info with metrics
   - `tquic_pm_nl_set_flags`: Update path flags (backup, priority)
   - `tquic_pm_nl_flush_paths`: Remove all paths for connection

   **Event sending** (`tquic_pm_nl_send_event`):
   - Rate limit using `__ratelimit()` with pernet event_rate_limit (pitfall #4)
   - Build event message with path metrics
   - Call `genlmsg_multicast_netns()` to TQUIC_PM_EV_GRP_OFFSET

   **Genetlink family**:
   ```c
   static struct genl_family tquic_pm_genl_family = {
       .name = TQUIC_PM_NAME,
       .version = TQUIC_PM_VER,
       .maxattr = TQUIC_PM_ATTR_MAX,
       .policy = tquic_pm_policy,
       .netnsok = true,
       .module = THIS_MODULE,
       .ops = tquic_pm_nl_ops,
       .n_ops = ARRAY_SIZE(tquic_pm_nl_ops),
       .mcgrps = tquic_pm_mcgrps,
       .n_mcgrps = ARRAY_SIZE(tquic_pm_mcgrps),
   };
   ```

2. Export init/exit functions for module lifecycle

3. Update Makefile to include pm_netlink.c

   - .name = "userspace"
   - .init = `tquic_pm_userspace_init`
   - .release = `tquic_pm_userspace_release`
   - .add_path = `tquic_pm_userspace_add_path` (validate then call core)
   - .del_path = `tquic_pm_userspace_del_path` (validate then call core)
   - .path_event = `tquic_pm_userspace_path_event` (forward to netlink)

   **Init/release**:
   - Init: Allocate per-connection userspace PM state, no notifier
   - Release: Clean up state, notify userspace via event

   **Path operations**:
   - add_path: Validate parameters, call tquic_conn_add_path, emit CREATED event
   - del_path: Find path, call tquic_conn_remove_path, emit REMOVED event

   **Event forwarding**:
   - path_event: Call tquic_pm_nl_send_event with event type and path metrics
   - Forward all events: ADDED, VALIDATED, FAILED, REMOVED, DEGRADED

2. In `include/net/tquic_pm.h`:

   - Add event type enum if not already defined

3. Register userspace PM ops alongside kernel PM in pm_types.c init
