<task type="auto">
  <name>Task 2: Implement kernel automatic path manager</name>
  <files>

    net/tquic/pm/Makefile

  <action>
Implement the kernel automatic PM following CONTEXT.md decisions and RESEARCH.md patterns:

1. Create `net/tquic/pm/pm_kernel.c` with:

   **Netdevice notifier callback** (`tquic_pm_kernel_netdev_event`):
   - Handle NETDEV_UP: Call `tquic_pm_kernel_try_add_path()` if interface passes filter
   - Handle NETDEV_DOWN: Call `tquic_pm_kernel_mark_unavailable()` to preserve state for fast recovery
   - Handle NETDEV_CHANGE: Update path state based on carrier status

   **Interface filtering** (`tquic_pm_kernel_should_add_path`):
   - Reject loopback: `dev->flags & IFF_LOOPBACK`
   - Reject bridge ports: `netif_is_bridge_port(dev)`
   - Reject OVS ports: `netif_is_ovs_port(dev)`
   - Reject MACVLAN: `netif_is_macvlan(dev)`
   - Reject ARPHRD_VOID and ARPHRD_LOOPBACK
   - Require IPv4/IPv6 address: `__in_dev_get_rtnl(dev)` has ifa_list
   - Require default route: use `fib_lookup()` pattern from RESEARCH.md
   - Check max_paths limit from pernet

   **Path discovery** (`tquic_pm_kernel_try_add_path`):
   - Hold RTNL lock during entire operation (pitfall #2)
   - Get addresses from interface
   - For each existing connection in namespace:
     - Check if path count < max_paths
     - If remote address known, call `tquic_conn_add_path()`
     - Set path state to TQUIC_PATH_PENDING (awaits validation)

   **struct tquic_pm_ops kernel_pm_ops**:
   - .name = "kernel"
   - .init = `tquic_pm_kernel_init` (register notifier)
   - .release = `tquic_pm_kernel_release` (unregister notifier)
   - .add_path = NULL (auto-managed)
   - .del_path = NULL (auto-managed)
   - .path_event = `tquic_pm_kernel_path_event` (internal tracking)

2. Register kernel PM ops in pm_types.c init

3. Export functions needed by tquic_main.c for connection setup
  </action>

- Verify netdevice notifier registration code present
- Verify interface filtering checks all required types
  </verify>
  <done>
Kernel PM automatically discovers paths when interfaces with default routes come up. Virtual interfaces are filtered. Path state preserved on interface down for fast recovery.

Connect the PM framework to connection creation and teardown:

1. In `include/net/tquic.h`:
   - Add `struct tquic_pm_state *pm` to `struct tquic_connection`
   - Add `u32 token` field for netlink identification (connection token)

2. In `tquic_socket.c` connect():
   - After connection established, call `tquic_pm_conn_init(conn)`
   - This selects PM type based on sysctl and calls ops->init

3. In `tquic_socket.c` close():
   - Before connection teardown, call `tquic_pm_conn_release(conn)`
   - This calls ops->release to clean up PM state

4. In `tquic_main.c`:
   - Add `tquic_pm_conn_init()` implementation:
     - Get pernet PM type
     - Allocate pm_state
     - Call selected PM's init callback
     - If kernel PM and auto_discover enabled, trigger initial discovery
   - Add `tquic_pm_conn_release()` implementation:
     - Call PM's release callback
     - Free pm_state

5. Generate unique connection token:
   - Use `get_random_u32()` at connection creation
   - Store in `conn->token` for netlink identification
